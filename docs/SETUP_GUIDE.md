# ZCode 会话统计 — 完整安装步骤（复刻作者本机效果）

> 目标效果：与作者机器一致——
> ① `/stats` 命令输出统计卡片；② 侧栏「会话统计」面板（5 秒自动刷新）；
> ③ 输入框下方居中的统计条（点击弹出明细，实时 TPS/缓存命中率/模型分布）；
> ④ 会话切换实时跟随、新会话显示空态。
>
> 预计耗时：10 分钟（含重启两次）。

## 0. 环境要求

| 项目 | 要求 | 检查方法 |
|---|---|---|
| 操作系统 | Windows 10/11 | — |
| ZCode Desktop | 3.17+（作者在 3.17.1 验证） | 关于页查看版本 |
| Python | 3.10+，且在 PATH 里 | 终端运行 `python --version` |
| Node.js | 18+（仅输入框统计条需要） | 终端运行 `node --version` |

任何一项缺失：Python 从 python.org 装并勾选 "Add to PATH"；Node 从 nodejs.org 装 LTS。

## 1. 安装插件（统计面板 + /stats 命令）

1. 打开仓库 https://github.com/huantest2024/zcode-session-stats
   → 绿色 **Code** 按钮 → **Download ZIP** → 解压到任意目录
   （例如 `D:\tools\zcode-session-stats`）
2. ZCode → 设置（Settings）→ **插件市场 / Plugin Marketplace**
   → **添加 / Add → Add Plugin Marketplace**
3. 粘贴**解压后的仓库根目录**（即含 `marketplace.json` 的那一层，
   例如 `D:\tools\zcode-session-stats`）→ 确认添加
4. 切换到该市场 → 找到 **会话统计 / session-stats** → **安装 / Install**
5. 确认版本 ≥ **0.2.7**（设置 → 插件管理里能看到）

> 也可以试直接粘贴 GitHub 仓库地址 `https://github.com/huantest2024/zcode-session-stats`
> 作为市场源（新版客户端支持 git 源时可跳过下载 ZIP）；不支持就用上面的 ZIP 方式。

## 2. 验证插件（先重启）

**完全重启 ZCode（或新建一个会话）**，然后：

- [ ] 在对话输入框敲 `/stats` 回车 → 输出统计卡片
      （`⏱ N 轮 M 步 · X tok/s`、`Σ X tok · 缓存命中 X%` + 明细）
- [ ] `/stats today` → 今日全部会话汇总
- [ ] 侧栏打开「会话统计」面板 → 显示统计卡片，正常对话时数字每 5 秒自动刷新
- [ ] 新建一个空会话 → 显示「新会话 · 暂无统计」，发第一条消息后开始计数

到此插件部分完成。数据来自本机 ZCode 的会话数据库（只读），每个机器显示自己的数字。

## 3. 输入框下方的统计条（可选，宿主补丁）

> 这是通过给 ZCode 宿主 `app.asar` 打补丁实现的（官方插件市场做不到这个位置）。
> 补丁脚本幂等、按版本自动备份、可一键还原；**ZCode 每次自动更新后需要重跑一次**。

1. **完全退出 ZCode**：右下角托盘图标也要退出（否则会提示「ZCode 正在运行」）
2. 双击仓库解压目录里的 **`patches\apply-patch.cmd`**
3. 预期输出最后一行：`✓ 补丁完成: app <版本> + patch 1.3.0（31850 文件 / ...）`
   （文件数随 ZCode 版本略有差异，以 ✓ 行为准）
4. 启动 ZCode → 任意会话的输入框下方出现居中的统计条：
   `⏱ N 轮 M 步 · X tok/s ｜ Σ X tok · 缓存命中 X%`
5. 点击统计条 → 上方弹出明细（耗时 / TTFT / token 分桶 / 模型分布）

**如果第 3 步报「目标文件被占用 / EPERM」**：等 10 秒再跑一次（杀毒软件对大文件的
瞬时扫描锁，脚本内置 5 次重试通常能自动过）；仍失败就重启电脑后立刻重跑。

## 4. 最终验收清单（与作者机器一致）

- [ ] `/stats` 与 `/stats today` 输出正确
- [ ] 侧栏面板打开且自动刷新
- [ ] 输入框下方统计条居中显示、与模型 id 同排观感
- [ ] 点统计条弹明细，滚动/缩放窗口时弹窗跟随且不出窗
- [ ] 切换会话（含空闲标签页）统计条数字即时跟随
- [ ] 新会话显示空态

## 5. 日常维护

| 情况 | 处理 |
|---|---|
| ZCode 自动更新后统计条消失 | 重跑 `patches\apply-patch.cmd`（1 分钟） |
| 想去掉输入框统计条 | 双击 `patches\restore-patch.cmd` 还原宿主 |
| 想卸载插件 | 设置 → 插件管理 → session-stats → 卸载 |
| 统计条突然不见了 | 通常是没有会话开着（数据服务随会话存活），打开/切回会话即恢复 |

## 6. 安全与隐私说明

- 插件**只读**访问本机 ZCode 会话数据库，无网络访问、无凭证、无遥测
- 附带的本地服务只绑定 `127.0.0.1`，仅响应 ZCode 自己的页面，其余来源一律 403
- 宿主补丁只改 `app.asar` 一个文件，自动按版本备份到 `app.asar.bak-<版本>`，
  `restore-patch.cmd` 可随时还原

## 7. 常见问题

**Q：统计数字和 ZCode 内置「使用统计」对不上？**
口径不同（如步数按逻辑请求去重、token 含缓存读），细粒度定义见插件 README 的
「指标口径」表；总量级应一致。

**Q：`/stats` 提示找不到工具？**
插件未装成功或未重启。设置 → 插件管理里确认 session-stats 已启用，然后新开会话。

**Q：双击 apply-patch.cmd 出现乱码/奇怪的「不是内部或外部命令」？**
用了旧版脚本。重新下载最新仓库 ZIP（脚本行尾问题已修复）。
